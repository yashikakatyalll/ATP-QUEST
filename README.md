⚡ ATP Quest

An interactive biology game focused on cellular respiration, metabolism, and ATP production.

Features
Interactive challenges and quizzes
Gamified biology learning
AI-powered content using the Gemini API
Cellular respiration and metabolic pathway activities
Built With
TypeScript
Gemini API
Netlify

💡 Why I Built It

I wanted to experiment with making biology more interactive instead of relying entirely on traditional studying and memorization.

ATP Quest combines game-based learning with AI to create a more engaging way to explore metabolic processes.
